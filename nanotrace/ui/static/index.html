03

              

                
How to Integrate in 3 Steps

                
Add NanoTrace to any Python agent or LLM application in seconds:

              

            


            

              
1

              

                
Initialize once in your project

                
Creates a local embedded DuckDB database file in ./.traces/nanotrace.duckdb.

                

                  import nanotrace

# Initialize local zero-overhead engine
nanotrace.init()
                

              

            


            

              
2

              

                
Decorate agents, tools, and subagents

                
Parent-child execution hierarchies, arguments, tool calls, and LLM steps are automatically tracked.

                

                  @nanotrace.trace_tool(name="search_database")
def search(query: str):
    return {"results": ["Relevant document content"]}

@nanotrace.trace_agent(name="ResearchAgent")
def run_agent(user_query: str):
    docs = search(user_query)
    with nanotrace.span("llm_reasoning", attributes={"gen_ai.request.model": "gpt-4o-mini"}):
        # Your OpenAI / Anthropic / Gemini call here
        return "Final agent answer"

run_agent("Evaluate AI systems")
                

              

            


            

              
3

              

                
Run Evaluations (DeepEval / Ragas / Heuristics)

                
Convert your traces directly into evaluation test cases without custom parsing.

                

                  # 1. Load traces into a TraceDataset
dataset = nanotrace.load_traces(limit=20)

# 2. Convert directly to DeepEval LLMTestCase objects
test_cases = dataset.to_deepeval()

# 3. Or convert to Ragas EvaluationDataset
ragas_dataset = dataset.to_ragas()

# 4. Or run instant local heuristic evaluators (0 tokens consumed!)
diagnostics = dataset.run_heuristics()
